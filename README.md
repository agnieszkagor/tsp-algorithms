Analysis and Comparison of Four Algorithms for the Traveling Salesman Problem

This repository contains the implementations of four algorithms for solving the TSP.
The project was developed as part of a Bachelor's thesis in Computer Science.

Following algorithms are implemented:
- Dantzig, Fulkerson, Johnson
- Lin-Kernighan
- Christofides' Algorithm
- Ant Colony Optimization

Data
The benchmark instances are obtained from TSPLIB.
